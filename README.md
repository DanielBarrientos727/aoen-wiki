# aoen WIKI

Enciclopedia fan independiente dedicada a **aoen**. Un espacio para descubrir a sus integrantes, conocer sus perfiles e historia, explorar su discografía y canciones, y seguir sus actividades.

El proyecto reúne información sobre el grupo en un solo lugar, con una interfaz diseñada para ofrecer una experiencia cómoda tanto en ordenadores como en dispositivos móviles.

**Contenido:** integrantes · perfiles · discografía · canciones · actividades · cronología · enlaces oficiales.

*Un proyecto fan, independiente y no afiliado oficialmente a aoen.*
